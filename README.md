# Livewire UI Lab

A growing collection of polished, reusable Livewire + Alpine components.

Think of it as a component buffet—pick what you like, leave the boilerplate behind.

## What's Inside?

- ✨ Inline Editing
- 🔔 Toast Notifications
- 🧙 Multi-Step Wizards
- 🏷️ Tag Inputs
- ♾️ Infinite Scroll
- 🔔 Notification Center
- 🔍 Dynamic Search
- 📋 Kanban Board
- ...and more.

## Why?

Because every project deserves components that feel smooth, responsive, and just a little bit magical—without dragging an entire frontend framework into the party.

Feel free to borrow, adapt, or shamelessly copy anything you find useful.

---

> Build once. Reuse everywhere. Debug... hopefully nowhere. 😄
